# 从填写到提交的工作流

本文给出从拿到模板到提交打印稿的完整流程。建议按顺序执行，并在每一步保留一个可编译的版本。

## 0. 准备工作

1. 复制整个 `qznu-thesis/` 目录，改名为自己的论文目录，例如 `2026-thesis/`。
2. 用 Git 或压缩包保留初始版本，便于格式改坏后回退。
3. 向指导教师或学院教学秘书确认：
   - 使用四种章节编号中的哪一种；
   - 英文摘要放在中文摘要后，还是按 2016 年打印格式放在参考文献后；
   - 前置部分页码是否用罗马数字；
   - 是否有学院固定封面、盲审/匿名要求；
   - 当年字数、参考文献数量、查重比例。

## 1. 选择章节编号

打开 `qznu-thesis.tex`，修改第一行：

```latex
\documentclass[scheme=2]{qznu-thesis}
```

- 文科、教育类常用 `scheme=2`；
- 理工科常用 `scheme=1`；
- 传统“第章”体例用 `scheme=3` 或 `scheme=4`。

只选一种，全文不要混用。模板会自动处理目录、图、表、公式编号。

## 2. 填写论文信息

编辑 `metadata.tex`：

1. 填写题目、副标题、英文题目；
2. 填写学院、专业、班级、学号、姓名、指导教师、职称、日期；
3. 填写中英文摘要和关键词；
4. 检查中文题目是否不超过 20 字、摘要是否 200--300 字、关键词是否 3--5 个。

摘要中如出现 `%`、`&`、`#`、`_` 等字符，需要转义或改写。长摘要可以放在单独文件中，用 `\input{}` 引入，避免 `metadata.tex` 过长。

## 3. 替换正文

`chapters/` 中的示例章节只是排版演示。建议：

1. 保留 `01-introduction.tex` 作为“绪论”模板；
2. 按自己的章节结构新建文件，例如 `02-literature.tex`、`03-method.tex`、`04-results.tex`、`05-conclusion.tex`；
3. 在 `qznu-thesis.tex` 中按顺序修改 `\input{}`；
4. 删除不再使用的示例章节，避免把示例数据带进正式论文。

每章用 `\chapter{...}`，每节用 `\section{...}`。不要手工输入“第一章”“1.1”等编号，模板会自动生成。

## 4. 插入图表、公式和参考文献

- 图片放在 `figures/`，用 `\includegraphics` 插入；图题在图下方。
- 表格用 `table` + `tabularx`/`booktabs`；表题在表上方。
- 公式用 `equation` 环境；用 `\eqref{}` 引用。
- 参考文献写入 `refs.bib`，正文用 `\cite{}` 引用；不要手写 `[1]`。
- 引用后至少运行两遍 XeLaTeX + BibTeX，`latexmk` 会自动处理。

交叉引用示例：

```latex
如图~\ref{fig:flow}所示，项目分为四个阶段。
如表~\ref{tab:project}所示，任务与目标一一对应。
如式~\eqref{eq:alpha}所示，α 系数用于检验内部一致性。
```

## 5. 编译

```bash
make
```

或：

```bash
latexmk -xelatex -interaction=nonstopmode -halt-on-error -outdir=build qznu-thesis.tex
```

首次编译会运行 XeLaTeX → BibTeX → XeLaTeX → XeLaTeX。若修改了目录、引用或页码，重新运行 `make` 即可。

## 6. 自动检查

```bash
make check
```

关注：

- 题目、摘要、关键词、正文、参考文献数量是否达标；
- PDF 是否为 A4；
- 中文字体是否嵌入；
- 是否有未定义引用；
- 是否有超过 5 pt 的 Overfull hbox；
- 版心是否为 16.5 × 25.7 cm。

自动检查通过不代表内容合格，仍需人工通读。

## 7. 人工检查版面

建议逐页检查以下位置：

1. 封面：字段是否完整、下划线是否对齐、题目是否换行过多；
2. 中文摘要：标签、字号、缩进、关键词；
3. 英文摘要：标题、作者信息、摘要、关键词；
4. 目录：章节是否齐全、页码是否与正文一致、是否有“???”；
5. 每章首页：标题编号、字号、段前距；
6. 图表页：图题在下、表题在上、图表是否超出边界、是否有孤行；
7. 公式页：编号是否右对齐、是否被页边距截断；
8. 参考文献：编号连续、作者、年份、页码、标点；
9. 致谢、附录：是否进入目录、附录编号是否为 A/B；
10. 页脚：页码是否连续、位置是否居中、封面是否无页码。

可用以下命令把 PDF 转成图片逐页检查：

```bash
mkdir -p build/preview
pdftoppm -r 100 -png build/qznu-thesis.pdf build/preview/page
```

## 8. 导出与打印

1. 将 `build/qznu-thesis.pdf` 另存为 `学号-姓名-论文题目.pdf`；
2. 用 Adobe Acrobat 或学校指定阅读器检查字体嵌入；
3. 按学院要求单面打印、装订；
4. 同时保留 `.tex` 源文件、`.bib`、图片和 PDF，便于修改；
5. 如学校要求 Word 版，LaTeX 不能直接替代 Word 归档要求，需按学院通知处理（可先用 `pandoc` 转 docx，再人工校对）。

## 9. 归档

按学校要求提交：

- 论文定稿 PDF；
- 论文源文件与图片；
- 查重报告；
- 开题报告、任务书、成绩表等过程材料；
- 外文翻译、文献综述等附件。

本模板只负责论文正文的排版，不生成上述过程表格。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `Font ... not found` | 字体集与系统不匹配 | 加 `fontset=fandol`，或安装对应中文字体 |
| `Missing character` | 字体缺字或生僻字 | 换用 Fandol/思源字体，或改用图片/替代字 |
| 引用显示 `[?]` | BibTeX 未运行或 key 拼错 | 运行 `make`，检查 `refs.bib` 的 key |
| 目录页码不对 | 需要多编译一遍 | 再运行一次 `make` |
| 图表跑到下一节 | 浮动体位置 | 调整 `[htbp]`，或适当移动源码位置 |
| 表格超出页边距 | 列宽之和过大 | 用 `tabularx`、缩小 `\tabcolsep`、缩短文字 |
| 页码从封面开始 | 误删 `\qznufrontmatter` | 保留主文件的分节命令 |
| 英文摘要位置不对 | 学院要求不同 | 移动 `\makeabstracten` 到参考文献后 |
| 打印后字体变细/变粗 | 字体替换 | 在打印店电脑上重新编译，或导出嵌入字体的 PDF |
