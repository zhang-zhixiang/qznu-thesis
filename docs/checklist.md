# 提交前检查清单

> 打印前逐项打勾。自动检查通过不等于内容合格。

## 一、内容与结构

- [ ] 中文题目不超过 20 字，能准确概括研究内容
- [ ] 英文题目与中文题目含义一致，大小写、专有名词规范
- [ ] 中文摘要 200--300 字，包含目的、方法、结果、结论
- [ ] 英文摘要与中文摘要对应，语法、术语准确
- [ ] 中文关键词 3--5 个，用中文分号分隔
- [ ] 英文关键词 3--5 个，与中文关键词对应
- [ ] 正文结构完整：绪论、理论基础/研究设计、实施/结果、结论
- [ ] 文科正文 8000 字以上；理科、艺术、体育 6000 字以上
- [ ] 参考文献 10 篇以上，正文引用与文献表一一对应
- [ ] 所有数据、引语、案例均有来源或明确说明
- [ ] 没有把示例数据、示例人名、示例学校信息留在正式论文中
- [ ] 致谢、附录按学院要求保留或删除

## 二、格式

- [ ] 纸张 A4，单面打印
- [ ] 上/下/左/右页边距 2.0 cm，左侧装订线 0.5 cm
- [ ] 页脚 1 cm，页码居中
- [ ] 封面字段完整，题目、学院、专业、班级、学号、姓名、指导教师、职称、日期无误
- [ ] 中文题目小二黑体加粗居中，副标题四号黑体
- [ ] 作者信息小四楷体加粗，上空一行、居中
- [ ] 中文摘要小五楷体加粗，标签小五黑体加粗，缩进 2 字符
- [ ] 英文摘要五号 Times New Roman
- [ ] 目录五号，章标题黑体、节标题宋体，点线连接页码
- [ ] 目录页码与正文一致，没有“???”
- [ ] 正文五号宋体，英文 Times New Roman，单倍行距
- [ ] 每段首行缩进 2 字符
- [ ] 一级标题四号黑体，二级标题小四黑体，三级标题五号黑体
- [ ] 四种章节编号只使用一种，全文统一
- [ ] 图题在图下方，表题在表上方，均居中
- [ ] 图、表、公式按章编号（图 3-1、表 3-1、式 (4-1)）
- [ ] 图表没有超出页边距，没有跨页断裂
- [ ] 公式编号右对齐，公式主体基本居中
- [ ] 参考文献标题五号黑体，条目五号宋体
- [ ] 正文引用为上标方括号，编号与文献表一致
- [ ] 附录中的图、表、公式编号为 A-1、B-1 形式
- [ ] 致谢、附录进入目录且页码正确

## 三、PDF 与打印

- [ ] `make check` 全部通过
- [ ] PDF 为 A4（595.28 × 841.89 pt）
- [ ] 中文字体已嵌入
- [ ] 没有未定义引用、Overfull hbox
- [ ] 封面没有页码，前置部分页码格式符合学院要求
- [ ] 逐页检查无孤行、孤段、图表错位
- [ ] 打印店试印 1--2 页，确认字体、页边距、装订线
- [ ] 按学院要求命名文件（如学号-姓名-题目.pdf）
- [ ] 保留 `.tex`、`.bib`、图片、PDF 源文件

## 四、提交材料

- [ ] 论文定稿 PDF
- [ ] 论文 Word 版（如学院要求）
- [ ] 查重报告
- [ ] 开题报告、任务书
- [ ] 指导教师评语、评阅书、答辩记录
- [ ] 外文翻译、文献综述
- [ ] 诚信承诺书
- [ ] 其他学院要求的表格

## 五、命令速查

```bash
make            # 编译
make check      # 内容 + PDF 检查
make test       # 四种编号方案回归测试
make view       # 打开 PDF
make clean      # 清理中间文件
```
