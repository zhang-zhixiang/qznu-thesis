\qznuappendix{附录 A　半结构化访谈提纲}\label{app:interview}

\section*{一、学生访谈提纲}

\begin{enumerate}[label=\arabic*.,leftmargin=2.5em]
  \item 在参加这个项目之前，你对泉州世界遗产了解多少？现在有哪些新的认识？
  \item 你们小组为什么选择这处遗产点？在确定主题时遇到过什么困难？
  \item 走访或访谈过程中，哪一件事或哪一个细节让你印象最深？
  \item 写解说词时，你最先考虑的是什么？修改过程中，你改变了哪些内容？
  \item 你们的作品是给谁看的？知道受众之后，你的表达有什么变化？
  \item 小组合作中，你承担了什么任务？遇到过意见不一致吗？最后怎么解决？
  \item 如果再来一次，你会在哪些方面做得不一样？
\end{enumerate}

\section*{二、教师访谈提纲}

\begin{enumerate}[label=\arabic*.,leftmargin=2.5em]
  \item 您如何理解语文综合性学习？在日常教学中，您通常怎样组织这类学习？
  \item 您认为地方世界遗产资源进入语文课程的价值和困难分别是什么？
  \item 在项目化学习中，您觉得学生最需要哪些支持？教师应扮演什么角色？
  \item 您如何评价学生在项目中的表现？过程性证据和最终成果各占多大比重？
  \item 您对学校层面支持项目化学习有什么建议？
\end{enumerate}
